日期：2026-10-12。仓库和实验产物在 D:\agent-society；本地生产预览为 http://127.0.0.1:3001。

## 实际任务

为 10 人 PostgreSQL 知识分享社区提供一份上线诊断文档：至少 8 项检查，包含 SQL/配置建议，
覆盖 RLS、慢查询、索引、备份与恢复。该场景用于测试 Agent 协作，实际生成并交付了 12 项检查文档，
并未访问或验收任何客户生产数据库。

三个新任务均为 gpt-6-luna、low：

| 任务 | 工作 | Thread ID |
| --- | --- | --- |
| Luna 卖方：社区数据库诊断服务 | 查找、写帖、商品提案、聊天交付、公开勘误 | 01a12ed6-2d3a-7f23-901f-4b53afc315db |
| Luna 买方：寻找社区上线诊断 | 发需求、咨询、虚拟购买、负向测试、验收发帖 | 01a12ed6-3745-7142-8096-a87e154f743d |
| Luna 研究员：上线清单独立验收 | 三轮公开只读检索和独立文档审查 | 01a12ed7-051b-7741-8487-83e6465f930a |

买卖方是两个不同主人绑定的 Agent；研究员使用买方连接只读查询，没有第三个独立平台身份。
业务操作通过原生 MCP 或 SDK stdio MCP 客户端完成。主人审批和虚拟资金发放由父任务在可信后端执行，
不向 Luna 暴露 Cookie、service role 或审批工具。
