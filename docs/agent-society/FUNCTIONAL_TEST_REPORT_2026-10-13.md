# 多会话逐功能测试报告

日期：2026-10-13。环境：D:\agent-society，本地生产服务 http://127.0.0.1:3000，本地 Supabase，Mock 模型及虚拟资金。

GitHub 归档：`test-evidence/2026-10-13/` 保存脱敏后的过程记录、失败尝试、数据库业务数据快照及 SHA-256 清单。原始本地数据未改动；认证表、密码、API 密钥及 Cookie 不对外发布。可通过 `node scripts/export-functional-evidence.mjs` 重新导出本地证据。

本轮由主会话和三个独立 Luna / low 测试会话执行。各组创建独立主人、Agent 和业务会话，不共用测试身份，不清空数据库。测试是实际 HTTP、MCP stdio 与 PostgreSQL 集成测试；不代表真实模型或链上支付已验证。

## 测试过程中修正的覆盖问题

主站 3000 未启用 `SOCIETY_SANDBOX_ORDERS`，实际 MCP 购买返回 `SANDBOX_DISABLED`。在独立 3002 实例通过进程环境开启该开关后，完整购买链路通过；临时实例已经停止，主站配置没有修改。因此主站当前仍不能直接进行沙箱购买。首次被开关阻止及后续断言修正的尝试均保留。

没有在本轮已覆盖场景中发现其他产品缺陷。发现并修正了测试本身的问题：

- 原跨 Agent 预算用例余额也不足，无法判断到底是哪种限制生效。补充足够余额，并明确检查预算错误；另建单独的余额并发用例。
- 同步 Mock 无法自然观察 RUNNING 窗口，旧结果曾将未执行的取消场景误标通过。旧记录保留并附 correction.json；使用受控待执行任务完成独立补测。
- 测试 Agent 名称长度、测试顺序和响应读取断言曾造成测试脚本失败；失败尝试保留，修正后的结果另存新目录。
- 社区脚本原本会删除测试主体，已改为保留。计费关闭脚本已改为每次独立目录，避免覆盖日志。

真实资金、真实模型供应商用量、x402 facilitator/链上结算、持续负载及完整浏览器交互均不在本轮通过声明内。测试凭证只保存在已被 Git 忽略的 `.local` 目录，请勿上传该目录。

## 再次运行

在项目根目录依次执行，下列脚本都会创建新的测试主体或过程记录：

```powershell
node scripts/test-functional-public.mjs
node scripts/test-society-local.mjs
node scripts/test-inference-multisession.mjs
node scripts/test-inference-running-cancel.mjs
node scripts/test-inference-budget-concurrency.mjs
node scripts/test-mcp-wallets.mjs
node scripts/test-mcp-orders.mjs
node scripts/test-inference-disabled.mjs
```

保留 3000 服务与本地数据库运行；计费关闭测试需要 3001 端口空闲。脚本不重置数据库，不删除上次测试数据。

`node scripts/test-mcp-stdio-purchase.mjs` 默认连接 3002，需要先启动启用 `SOCIETY_SANDBOX_ORDERS=true` 的本地测试实例；也可用 `SOCIETY_TEST_URL` 指定已开启该功能的本地实例。此脚本不会自行启动服务器。
